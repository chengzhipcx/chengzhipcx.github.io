为什么是 Python？

  • Python 与 AI 密不可分 — 几乎所有主流机器学习框架（TensorFlow、PyTorch）的首选接口语言
  • 方便灵活、简单易用 — 语法接近自然语言，学习曲线平缓
  • 生态丰富 — NumPy、Pandas、Scikit-learn、Matplotlib 等库开箱即用
  • 开发速度快 — 同样的算法，Python 开发 1 小时 ≈ C++ 开发 10 小时

Python 性能真相

维度 Python C++
1~100万累加（重复100次） ~10 s ~0.3 s
开发同样功能耗时 ~1 小时 ~10 小时
适合场景 上层逻辑、快速验证 底层算法、性能瓶颈

💡 策略： Python 写上层逻辑，C/C++ 写底层算法，通过 NumPy 等库暴露 Python 接口 —— 各取所长，有机融合

Python 的语言属性

按执行方式

编译型 ：C、C++ — 先编译再运行，速度快

解释型 ：Python、JavaScript — 逐行解释执行，灵活

按类型声明

静态语言 ：Java、C++ — 变量类型需预先声明

动态语言 ：Python — 变量类型运行时自动推断

Python = 解释型 + 高级语言 + 动态语言

Python 发展简史

  • 1989 — 荷兰程序员 Guido van Rossum 开发 Python（大蟒蛇）
  • 1991 — 第一个可用版本问世
  • 2000 — Python 2.0 发布
  • 2008 — Python 3.0 发布（自我革命，不兼容 2.x）
  • 2010 — Python 2.x 发布最后一个版本
  • 2016 — 几乎所有重要库完成 Python 3 迁移
  • 现在 — Python 3.x 持续迭代更新，3.12+ 为主流

⚠️ 本课程使用 Python 3.x ，不再涉及 Python 2 相关内容

环境配置：Anaconda

Anaconda 是数据科学领域最常用的 Python 发行版，内置了 NumPy、Pandas 等常用库

# 1. 下载并安装 Anaconda（官网：anaconda.com）
# 2. 创建独立的 Python 环境
conda create -n pyml python=3.11
# 3. 激活环境
conda activate pyml
# 4. 安装机器学习常用包
conda install numpy pandas matplotlib scikit-learn
conda install jupyter notebook

学习建议

  • 动手 > 看 — 每看完一节就打开 IDE 敲一遍代码，不要只看不练
  • 先跑通，再深究 — 不要卡在语法细节上，先让代码跑起来，再回头理解
  • 善用搜索引擎 — Python 报错信息通常很直观，复制到 Google/百度就能找到答案
  • 坚持打卡 — 每两章有一次作业讲解，跟上节奏比突击更有效
  • 以用促学 — 结合机器学习课程中的实战项目来巩固 Python 语法
